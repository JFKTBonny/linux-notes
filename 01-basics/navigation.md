# Navigation

Moving around the filesystem.

## Show your current directory

```bash
pwd
```

## List files, including hidden ones, with details

```bash
ls -la
```

## Change directory

```bash
cd /var/log
```

## Go to your home directory

```bash
cd ~
```

## Go up one level

```bash
cd ..
```

## Go back to the previous directory

```bash
cd -
```
