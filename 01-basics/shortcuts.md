# Shortcuts

Keyboard shortcuts that save time in the terminal.

| Keys | Action |
|---|---|
| Tab | Autocomplete |
| Ctrl+C | Stop current command |
| Ctrl+R | Search command history |
| Ctrl+L | Clear screen |
| ↑ / ↓ | Previous / next command |

## Get help on any command

```bash
man tar
```

## Quick help summary

```bash
tar --help
```
