# Sample Data

Small files used by the sed, cut and awk examples.

| File | Content |
|---|---|
| `users.csv` | Comma-separated table with a header row |
| `access.log` | Web server log in common log format |
| `app.conf` | `key=value` config with comments and blank lines |

Examples that edit files in place work on a copy first, so these originals stay unchanged.
