# Packages

Installing and updating software.

## Debian / Ubuntu: refresh package lists

```bash
sudo apt update
```

## Debian / Ubuntu: upgrade installed packages

```bash
sudo apt upgrade
```

## Debian / Ubuntu: install a package

```bash
sudo apt install htop
```

## Debian / Ubuntu: remove a package

```bash
sudo apt remove htop
```

## Fedora / RHEL: install a package

```bash
sudo dnf install htop
```

## Fedora / RHEL: upgrade installed packages

```bash
sudo dnf upgrade
```
