# Processes

Viewing and stopping running programs.

## Show running processes

```bash
ps aux
```

## Live process monitor

```bash
top
```

Press `q` to quit.

## Find a process by name

```bash
pgrep -a nginx
```

## Stop a process by ID

```bash
kill 1234
```

## Force-stop a process

```bash
kill -9 1234
```
